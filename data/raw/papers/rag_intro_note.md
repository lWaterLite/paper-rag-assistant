# RAG 入门笔记

RAG 是 Retrieval-Augmented Generation 的缩写，中文通常称为检索增强生成。

它的基本思想是先从外部知识库中检索相关资料，再把资料作为上下文交给语言模型生成回答。

RAG 的价值不只是让模型回答得更准确，还包括让回答具备引用来源和可追溯性。

一个完整的 RAG 系统通常包含文档加载、文档解析、文本切分、索引构建、检索、重排、上下文组织、回答生成、引用校验和评测。

离线索引流程负责把文档变成可检索的索引。在线问答流程负责根据用户问题检索资料并生成答案。

如果检索阶段没有召回正确片段，那么生成阶段很难产出可靠答案。因此 RAG 的上限通常由检索质量决定。
